Dev Notes
🔐 Authentication
OTP via SMS (primary). SSO via SAML 2.0 / OAuth 2.0 (if Aramco IdP confirmed)
JWT short-lived tokens + refresh rotation, tied to device fingerprint
Biometric re-auth for subsequent unlocks
POST /auth/otp/request POST /auth/otp/verify → { access_token, refresh_token }
🔐 OTP Flow
6-digit OTP, 5-min expiry, 3 attempt limit before lockout
Auto-read OTP from SMS via Android SMS Retriever API
Resend with 60s cooldown, max 3 resends
// Android SMS Retriever SmsRetrieverClient client = SmsRetriever.getClient(this);
📅 Shift & Route
Shift data fetched at login + cached to SQLite for offline use
Visit order from backend (proximity algorithm) — non-reorderable without supervisor override
Map via Google Maps SDK for Android (or Mapbox for offline tile support)
GET /shifts/today → { visits[], route, cached_at } // Stored in SQLite on device
📡 NFC Scanning
Android NFC API (NfcAdapter). Foreground dispatch for active scan mode
Read NDEF message + UID from NTAG213/215/216 (TBC with Aramco)
UID validated against work order via API (or cached map offline)
QR/barcode fallback via ML Kit Barcode Scanner
// NFC Intent NfcAdapter.ACTION_NDEF_DISCOVERED → extract UID → validate(uid, workOrder) → MATCH | MISMATCH | NOT_FOUND
✅ Tag Validation
UID binding stored in backend — no UID spoofing possible
GPS geofence check: must be within configurable radius (default 50m) of sample point coordinate
All scan events logged immutably (UID, timestamp, GPS, result)
// Validation response { matched: true, point: "SP-003", gps_delta_m: 8, authorised: true }
☑️ Checklist Engine
Checklist items are backend-configurable per sample type and hazard zone
All items must be checked before "Start Collection" unlocks
Checklist completion logged as CoC "Picked" event with timestamp + GPS
// Checklist config (backend) { sample_type: "crude_oil", items: [ { id, label, mandatory } ], cached: true }
🧪 Data Capture
GPS auto-captured via FusedLocationProvider. Accuracy threshold configurable
Photos: CameraX API, JPEG compressed <800KB, EXIF geo-tagged
Temperature: manual entry or Bluetooth sensor (future hook)
CoC events written atomically to local DB + sync queue
// Offline queue entry { visit_id, type: "SEALED", ts_utc, gps, photos[], synced: false }
📄 Report Generation
PDF generated on-device using iText / Android PDF Canvas API
Template: Aramco-branded, bilingual (EN/AR), embedded photos + map thumbnail
Signature captured via touch canvas, embedded as PNG in PDF
Share via Intent to email, WhatsApp, or any Android share target
// PDF output visit_report_SP003_20260310.pdf Shared via: ACTION_SEND intent
🔄 Sync & Offline
WorkManager for background sync — fires when connectivity restored
Sync queue: ordered by timestamp, retry on failure with exponential backoff
Conflict resolution: server authoritative for config; field data always preserved
// WorkManager constraint Constraints.Builder() .setRequiredNetworkType( NetworkType.CONNECTED) .build()
🛠 Tech Stack
Kotlin Android NFC API CameraX SQLite WorkManager FCM ML Kit iText PDF Maps SDK AES-256 TLS 1.3 JWT
